# RISC-V Disassembler

Консольный дизассемблер на C, который преобразует машинный код RISC-V из ELF-файла в читаемый ассемблерный листинг. Программа показывает адреса и коды инструкций, восстанавливает имена меток из таблицы символов и обозначает цели переходов.

Проект разработан в рамках курса архитектуры компьютера в ИТМО. В основе реализации — самостоятельный разбор бинарного формата ELF32 и декодирование инструкций битовыми операциями, без сторонних библиотек дизассемблирования.

## Возможности

- Чтение ELF32 в формате little-endian: секции `.text`, таблицы символов `.symtab` и связанных строковых таблиц.
- Декодирование арифметических и логических инструкций RV32I, сдвигов, загрузки и сохранения данных, условных переходов, `jal`, `jalr`, `lui`, `auipc`, а также `ecall` и `ebreak`.
- Поддержка расширения RV32M: умножение, деление и вычисление остатка, включая знаковые и беззнаковые варианты.
- Вывод регистров по ABI: `zero`, `ra`, `sp`, `a0`–`a7` и другие.
- Использование имён символов для меток и создание меток `L0`, `L1`, … для целей переходов без имени.
- Вывод таблицы символов с адресами, размерами, типами, привязкой, видимостью и индексами секций.

Инструкции выводятся без замены на псевдоинструкции: например, `addi zero, zero, 0` сохраняется в исходном виде.

## Сборка и запуск

Нужен компилятор C с поддержкой C23, например GCC или Clang.

```sh
cc -std=c23 -O2 main.c -o disassembler
./disassembler input.elf output.txt
```

Первый аргумент — входной ELF-файл, второй — путь к текстовому файлу результата. Для компиляторов, использующих предварительное название стандарта C23, флаг сборки — `-std=c2x`.

Выходной файл содержит две части, разделённые пустой строкой: `.text` с дизассемблированным кодом и `.symtab` с таблицей символов. Пример фрагмента листинга:

```text
.text
00010074 <main>:
   10074:  00000013     addi  zero, zero, 0
   10078:  00100137      lui  sp, 256
```

## Как устроено

1. Программа читает бинарный файл и по заголовкам ELF находит код, таблицу символов и строки с именами.
2. Разбивает `.text` на 32-битные инструкции, извлекает поля `opcode`, `funct3`, `funct7`, регистры и непосредственные операнды.
3. Вычисляет адреса переходов и связывает их с существующими или автоматически созданными метками.
4. Записывает ассемблерный листинг и таблицу символов в выходной файл.

Основная логика находится в `main.c`, определения структур ELF и промежуточного представления инструкций — в `elf_args.h`.

## Область применения

Программа рассчитана на корректные ELF32-файлы RISC-V с секциями `.text` и `.symtab` и 32-битными инструкциями. Сжатые инструкции RVC и ELF64 не поддерживаются. Полная поддержка RV32I пока не реализована: в частности, `fence` не декодируется.
